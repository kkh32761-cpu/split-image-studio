# 6분할 이미지 스튜디오

사진을 원하는 구도로 편집해 플랫폼에 등록할 이미지 6장을 만드는 한국어 웹 도구입니다. 사진 읽기, 편집, 압축, ZIP 생성은 브라우저 안에서 이뤄집니다. 로그인이나 설치 없이 사용할 수 있습니다.

## 사용하기

1. JPG, PNG, WEBP 또는 GIF를 선택하거나 드래그해서 놓습니다. GIF는 첫 프레임을 사용합니다.
2. 드래그로 사진을 옮기고 휠이나 오른쪽 슬라이더로 확대·축소합니다. 휠의 확대 중심은 포인터입니다. `Shift`를 누른 채 휠이나 `±` 버튼을 사용하면 더 작은 폭으로 조절할 수 있습니다. 배율 칸에 `103.5`처럼 직접 입력하고 `Enter`를 눌러도 됩니다. **맞추기**는 사진 전체를 보여주고, **채우기**는 여백 없이 프레임을 덮습니다.
3. 플랫폼 미리보기를 확인하고 **6장 생성 + ZIP 다운로드**를 누릅니다. 결과가 나오면 개별 다운로드나 ZIP 다시 다운로드도 사용할 수 있습니다.

드래그 중 사진의 중심이나 상하좌우 끝이 프레임의 같은 위치에 가까워지면 **중앙·가장자리 자동 맞춤**이 해당 축을 맞추고 점선을 보여줍니다. 설정에서 끄거나 `Alt`를 누른 채 드래그하면 자유롭게 움직일 수 있습니다. 캔버스에 초점을 맞춘 뒤 방향키로 사진을 옮기고 `+` 또는 `-`로 확대·축소할 수 있습니다.

## 출력 규격

| 항목 | 값 |
| --- | --- |
| 배치 | 2열 × 3행 |
| 저장 크기 | 720 × 150px |
| 플랫폼 표시 크기 | 칸당 441 × 92px |
| 전체 표시 크기 | 883 × 278px |
| 칸 사이 간격 | 가로·세로 1px, 미리보기에 검은색 표시 |
| 용량 상한 | 각 이미지 200,000바이트 |

전체 표시 영역에서 시작 좌표가 `x = 0, 442`, `y = 0, 93, 186`인 441×92 영역을 각각 추출합니다. 원본은 가로와 세로에 동일한 편집 배율을 사용합니다. 각 칸을 720×150으로 저장할 때는 표시 크기로 돌아갈 수 있도록 축별 출력 배율을 따로 적용합니다. 검은 간격은 미리보기의 배경에만 포함합니다.

자동 최적화는 JPG 원본으로 완전히 채운 칸에 JPG를 사용하고, 다른 칸은 PNG를 우선 시도합니다. PNG 우선 모드는 모든 칸에서 PNG를 먼저 시도합니다. PNG가 상한을 넘으면 흰색 배경의 JPG로 변환하고 품질을 조절합니다. 미리보기의 투명 영역도 흰색으로 표시합니다.

파일명은 `01_top_left`, `02_top_right`, `03_middle_left`, `04_middle_right`, `05_bottom_left`, `06_bottom_right` 순서입니다. 확장자는 각 칸의 실제 형식과 일치합니다.

## 실행 및 GitHub Pages 배포

- 로컬에서 `index.html`을 브라우저로 열 수 있습니다. CSS와 JavaScript는 같은 폴더에 두세요. 별도 설치와 인터넷 연결이 필요 없습니다.
- GitHub Pages에서 이 폴더의 내용을 저장소 루트에 올린 뒤 **Settings → Pages → Deploy from a branch**에서 `main`과 `/(root)`를 선택합니다. 다른 기본 브랜치를 쓰는 저장소는 그 브랜치를 선택합니다.
- `image-core.js`에 프리셋, 좌표 변환, 인코딩, ZIP 로직이 있습니다. `studio.js`에서 편집 동작과 미리보기, 다운로드를 연결합니다. `.nojekyll`은 GitHub Pages가 정적 파일을 그대로 제공하도록 설정합니다.

원본의 크기나 해상도에 서비스 자체 상한을 두지 않습니다. 브라우저의 이미지 디코더와 기기 메모리가 처리 가능한 범위를 결정합니다. 32MP 이상 또는 40MB 이상이면 처리 시간과 메모리 안내를 표시합니다.
